# Умный центр

Это веб‑проект для учебного центра, где в одном месте собраны основные процессы: заявки с сайта, ученики и родители, группы, расписание, оплаты, абонементы, домашние задания, обращения родителей и CRM для администратора.

## Что реализовано

- **Публичная часть сайта** 
- **CRM для администратора** 
- **Воронка продаж** 
- **Расписание и посещаемость** 
- **Абонементы и оплаты** 
- **Коммуникация с родителями** 
- **Домашние задания** 
- **AI‑помощник для администратора** 

## Какие задачи закрывает

Система помогает:

- не терять входящие заявки;
- видеть, на каком этапе находится каждый потенциальный клиент;
- быстрее переводить заявку в ученика;
- хранить данные учеников, родителей и преподавателей в одном месте;
- управлять курсами, группами и тарифами;
- контролировать расписание занятий;
- учитывать посещаемость;
- следить за остатком занятий по абонементам;
- видеть платежи и статусы оплат;
- обрабатывать обращения родителей;
- давать администратору понятную картину по текущей работе центра.
